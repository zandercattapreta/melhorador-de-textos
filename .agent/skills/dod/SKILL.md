# DoD — Melhorador de Textos

Consulte o DoD universal em:
`~docs/~work_guidelines/protocols/DOD.md`

## Critérios adicionais deste projeto

- [ ] Escopo aprovado atendido; nada além do pedido.
- [ ] Quando a stack existir: build, testes e lint limpos.
- [ ] Nesta fase (scaffold): estrutura `.agent/`, `AGENTS.md` e docs mínimas consistentes.
- [ ] Texto processado não introduz conteúdo ausente na fonte OCR/PDF.
- [ ] Sem secrets, `.env` ou PDFs brutos no diff.
- [ ] `_docs/BACKLOG-MELHORADOR.md` / `_docs/CHANGELOG.md` atualizados quando a convenção ou o estado mudam; `check-docs.sh` verde.
